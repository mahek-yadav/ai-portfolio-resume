## How to Capture Screenshots on macOS

1. Ensure both frontend (`http://localhost:5173`) and backend (`http://localhost:5001`) are running.
2. Open your browser in full screen or a clean window at `100%` zoom.
3. Use the macOS shortcut:
   - **`Command + Shift + 4`**, then press **`Space`** and click the browser window to capture a clean window screenshot with drop shadow.
   - Or **`Command + Shift + 4`** to select an exact region.
4. Save the files into this `screenshots/` directory with the respective names listed in the checklist above.
